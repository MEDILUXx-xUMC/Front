## 동작과 검토 범위

- O5의 다섯 `보기`는 해당 약관 본문을 O8 정책과 동일한 읽기 UI로 연다. 끝까지 스크롤하면 동의 버튼이 활성화되고, 버튼을 누르면 O5의 해당 항목만 체크한다. 뒤로가기만으로 동의하지 않는다.
- O5 필수 다섯 항목에 동의해야 계속할 수 있다. 혜택·이벤트 알림은 선택이다. 전체 동의는 전체 선택·해제이며 일부만 선택되면 중간 상태를 표시한다.
- O8은 보증금과 문고리 정책을 별도로 읽고 동의해야 등록할 수 있다. O8-2, O8-4는 완료 화면을 직접 검토하는 경로다. 단순히 화면을 열었다고 동의 처리하지 않는다.
- 읽기 100%에서 별도 확인 체크 때문에 동의 버튼이 잠기던 문제를 수정했다. 마지막 줄까지 읽으면 읽음 상태가 표시되고 동의 버튼을 바로 누를 수 있다. 실제 동의는 버튼을 누른 때 반영한다. 끝까지 읽기 전에는 100%로 반올림하지 않는다.
- 정책 본문은 Figma 초안을 옮겼다. Figma에 없는 O5 약관 본문은 화면 검토용 초안이다. 운영 전 확정된 약관, 시행일, 개인정보 수집 항목·보유기간을 받아 교체해야 한다.
- 로그인, 위치, 결제수단 등록은 Mock이며 외부 인증·위치·결제 API를 호출하지 않는다. 카드 입력은 현재 페이지의 메모리에만 있고 등록 시 앞 비밀번호와 전체 번호를 지운다. 완료 요약에는 끝 네 자리만 남긴다.
- 소개·약관·권한 안내에 불필요한 스켈레톤을 추가하지 않는다. 동네 검색 결과만 스켈레톤으로 표시하고 로그인·인증·등록에는 중복 실행을 막는 버튼 로딩을 표시한다.
- 기존 공통 UI 함수와 색상 토큰을 재사용한다. 기존 화면 동작을 바꾸지 않고 온보딩 전용 스타일로 범위를 제한한다.
- Figma의 Noto Sans KR을 온보딩에 한정해 로컬 웹폰트로 제공한다. 설치된 원본 가변 글꼴에서 한글·영문·UI 기호를 WOFF2로 변환했으며 라이선스는 `public/fonts/OFL.txt`에 포함했다.

## 실행

`npm ci`, `npm run dev` 후 Vite의 기본 주소에서 서비스 소개를 확인한다. 타입 검사와 빌드는 `npm run typecheck`, `npm run build`로 실행한다.
